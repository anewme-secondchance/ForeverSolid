# Forever Solid Clothing Store

## Overview

This website allows customers to browse Forever Solid apparel, place an order, and pay through Cash App.

---

## How Orders Work

1. Customer selects a product.
2. Customer chooses:
   - Size
   - Color
   - Quantity
3. Customer enters their contact information.
4. Customer selects Pickup or Shipping.
5. Customer pays using Cash App.
6. Customer texts **(903) 262-9694** with:
   - Name
   - Product Ordered
   - Size
   - Color
   - Quantity
   - Pickup or Shipping
   - Screenshot of Cash App payment

After payment is verified, the order is processed.

## Changing Product Images

Place all product images inside:

```
images/
```

Update the image filename in the appropriate HTML page.

Example:

```html
<img src="../images/shirt1.jpg">
```

---

## Changing Prices

Edit the product page or collection page and change the displayed price.

Example:

```
$25
```

to

```
$30
```
